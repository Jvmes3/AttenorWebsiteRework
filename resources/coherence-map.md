# Coherence Map

A tool for helping your team move from knowing the strategy to being able to speak to it.

## Through-lines

- What are the core ideas that connect the strategy?
- Which phrases, commitments, or choices need to show up consistently?

## Framework anchors

- How does each team, initiative, or decision connect to the strategic framework?
- Where does the connection feel strong?
- Where does the connection need to be clarified?

## Shared language

- What words should everyone be able to use with confidence?
- Where are people using the same words but meaning different things?

## Communication readiness

- What should leaders be able to say in one clear sentence?
- What story should the organization be able to tell together?
